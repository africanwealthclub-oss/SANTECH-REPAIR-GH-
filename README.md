# SANTECH REPAIR GH

Premium Next.js homepage for SANTECH REPAIR GH, a phone and electronics repair and sales business in Ghana. The site uses the supplied SANTECH logo, orange/yellow/charcoal brand palette, responsive App Router UI, Tailwind CSS, Lucide icons and a WhatsApp enquiry pathway.

Product cards use clearly marked placeholders for prices and availability until the business confirms those details.

```bash
npm install
npm run dev
npm run build
```
